How ranking works
  • Filters (matching.yaml) remove only jobs you can't or won't do: hard exclusions, too senior, location. The stack never filters. Nothing is deleted: see Browse → Filtered.
  • Score 0–10 from your profile. 7.0 is a full score from the job description; 6.5 is preliminary, from the alert alone (at most 7).
  • Rank = score, +0.5 if seen in the last 3 days, −1 if older than 3 weeks, +1 for watchlist companies{% if watchlist %} ({{ watchlist|join(", ") }}){% endif %}, minus soft penalties (stacks you'd rather avoid). Full scores win ties.
  • Apply today takes the top {{ n }}{% if days %} from the last {{ days }} days of alerts{% endif %}, only with a verified experience level{% if max_stretch is not none %} (at most {{ max_stretch }} stretch){% endif %}{% if family_pct %}, and no stack family takes more than about {{ family_pct }}%{% endif %}.   • Expired: not in any alert for {{ expire_days or 14 }} days, or the posting is closed.
